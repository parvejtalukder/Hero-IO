# Hero-IO

## Description
Hero-IO is a responsive web application that allows users to explore, search, and install mobile apps. It features detailed app information, live search, installation tracking with localStorage, and review visualization using charts. Users can sort apps by downloads and manage their installed apps easily.

## Features
- Responsive design for all devices
- App installation tracking with localStorage
- Live search and filtering of apps
- Sorting apps by downloads (High-Low, Low-High)
- Detailed app pages with descriptions, ratings, and charts
- Custom error page for invalid routes
- Smooth navigation with loading animations

## Technologies Used
- **Frontend:** React.js, Vite, TailwindCSS, DaisyUI  
- **Charts:** Recharts  
- **Routing:** React Router  
- **State Management:** React Hooks (useState, useEffect)  
- **Data:** JSON for app data  
- **Deployment:** Netlify
